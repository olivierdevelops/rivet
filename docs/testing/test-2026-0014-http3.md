## Test Data

Test fixtures and bundles defined in `tests/conformance_http3.rs` and the shared helpers under `tests/` (in-process servers, temporary directories).

## Procedure

```sh
cargo test --workspace --all-targets --all-features --no-fail-fast   # full run → /tmp/p3-tests.log
cargo test --all-features --test conformance_http3
```

Tests executed (7):

- `conformance_http3::demo_09_quic_items_http3` — docs/demos/09-quic items.http3 returns {items: [], version: 3} against the local h3 fixture; the bundle's QUIC-only policy.json denies it before any I/O
- `conformance_http3::h3_stream_scope` — `with http … version 3 stream lines` iterates an HTTP/3 body and exposes response.version 3
- `conformance_http3::policy_denial_sends_zero_packets` — without an https grant the H3 request is denied (permission.denied, exit 3) and zero UDP packets are sent
- `conformance_http3::post_with_lost_response_is_not_replayed` — a POST whose H3 response is lost fails (exit 5) and is not re-sent over h2: exactly one mutation
- `conformance_http3::prefer_falls_back_only_when_h3_handshake_fails` — `version prefer [3, 2]` uses H3 when available and falls back to h2 when the H3 handshake fails before any request byte; response.version reports 3 or 2
- `conformance_http3::strict_h3_success` — strict `version 3` completes over HTTP/3 against the h3 fixture and response.version is 3
- `conformance_http3::strict_h3_to_h2_only_server_does_not_downgrade` — strict `version 3` to an h2-only server fails http.version_unavailable (exit 5) and never downgrades

v0.1.0 run: `cargo test conformance_http3`.
