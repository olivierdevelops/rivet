Tests executed (18):

- `conformance_grpc::auth_attaches_bearer_and_reserved_metadata_rejected` — `auth PROFILE account A` attaches an origin-bound OAuth bearer after the method/network permits (none without allow_auth, and nothing dials); reserved metadata is rejected
- `conformance_grpc::bidi_concurrent_send_and_receive` — bidirectional: a send task and a receive task progress independently under `concurrent`; completion follows OK
- `conformance_grpc::cli_live_input_local_and_remote` — CLI `request chat.exchange --input-jsonl - --stream` locally (Runtime::dispatch_session) and against serve (/v1/ws frames): echoes stream while stdin is open, EOF finishes input, the result is the OK completion; a schema-invalid line cancels with validation.input (exit 2)
- `conformance_grpc::client_stream_upload` — client streaming sends a finite list, half-closes and reads one result after OK
- `conformance_grpc::deadline_is_timeout` — the `timeout` option bounds the call; DEADLINE_EXCEEDED is a timeout, distinct from UNAVAILABLE
- `conformance_grpc::demo_10_grpc_flows` — docs/demos/10-grpc compiles and its README flows (unary, watch, late UNAVAILABLE, upload) run against the fixture
- `conformance_grpc::early_break_cancels_the_stream` — breaking out of an endless server stream cancels the owned call at scope exit
- `conformance_grpc::early_server_finish_closes_input` — early server finish: the receive side still reports the real OK status and later sends fail grpc.input_closed
- `conformance_grpc::fixture_descriptors_match_the_demo_schema`
- `conformance_grpc::load_time_descriptor_checks` — bundle load fails on a missing descriptor, unknown method or a call form that contradicts the descriptor cardinality
- `conformance_grpc::partial_stream_then_unavailable` — S117: one message then UNAVAILABLE trailers is one terminal grpc.unavailable error (exit 5) that keeps the emitted item
- `conformance_grpc::policy_denial_before_dialing` — policy: a missing allow_grpc method grant or network grant is permission.denied before any connection
- `conformance_grpc::private_resolved_address_is_refused` — a DNS name resolving to a private address is refused unless that address is granted literally or private ranges are allowed
- `conformance_grpc::protojson_mapping_round_trips` — ProtoJSON mapping: int64/uint64 as decimal strings, bytes base64, map, oneof, enum names, presence, Timestamp and non-finite doubles round-trip losslessly
- `conformance_grpc::server_stream_then_completion` — server streaming emits every message in order, then completion reports the final OK
- `conformance_grpc::tls_with_ca_file` — https endpoints verify the server with `tls ca_file` (an allow_read site) and `tls server_name`
- `conformance_grpc::unary_get_user` — unary GetUser returns GrpcResponse {message, initial_metadata, trailers, status} only after OK; metadata is sent and secrets in response metadata are redacted
- `conformance_grpc::unary_status_mapping` — non-OK statuses map to the registry: NOT_FOUND, PERMISSION_DENIED, UNAUTHENTICATED, and a second unary response is a protocol error
